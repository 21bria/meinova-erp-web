# Meinova ERP Web

Modern Enterprise Resource Planning (ERP) Web Application built with Nuxt 4, Vue 3, TypeScript, and Tailwind CSS.

---

## Features

- Modern Dashboard
- Multi-Tenant Ready
- Responsive Design
- Dark / Light Mode
- Authentication
- Role Based Navigation
- Dynamic Forms
- CRUD Generator
- Workspace Editor
- Data Tables
- Charts & Reports
- File Upload
- Notification System
- Settings Management

---

## Technology Stack

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS
- shadcn-vue
- Pinia
- VueUse
- Plotly
- Axios

---

## Requirements

- Node.js 22+
- pnpm

---

## Installation

Clone repository

```bash
git clone https://github.com/21bria/meinova-erp-web.git
cd meinova-erp-web
```

Install dependencies

```bash
pnpm install
```

Copy environment

```bash
cp .env.example .env
```

Run development server

```bash
pnpm dev
```

---

## Build

```bash
pnpm build
```

Preview

```bash
pnpm preview
```
