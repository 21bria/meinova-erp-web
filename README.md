# Meinova ERP Web

Modern Enterprise Resource Planning (ERP) Web Application built with Nuxt 4.

## Tech Stack

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS
- shadcn-vue
- Pinia
- VueUse

## Requirements

- Node.js 22+
- pnpm

## Installation

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```
